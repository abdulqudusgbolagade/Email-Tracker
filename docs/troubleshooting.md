# Troubleshooting

| Symptom                                        | Diagnosis and action                                                                                                                                                                                                                                                            |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Owner account unavailable                      | Run `npm run setup` in an interactive terminal. There is no public signup or default password.                                                                                                                                                                                  |
| Request origin rejected                        | Browser hostname/scheme/port must match `APP_URL`; restart both processes after edits. A reverse proxy must preserve Origin.                                                                                                                                                    |
| CSRF rejected                                  | Refresh the signed-in page. Expired sessions require signing in again. Do not disable the check.                                                                                                                                                                                |
| Prisma downloads denied                        | Allow `binaries.prisma.sh` in environment networking, then rerun `npm ci`/setup. Keep checksum and TLS verification enabled.                                                                                                                                                    |
| Prisma reports a fresh-database error          | Use setup, which creates the database's parent directory and empty SQLite file before migrations. Paths are resolved from the repository root.                                                                                                                                  |
| Saved credentials cannot decrypt               | Restore the matching `CREDENTIAL_ENCRYPTION_KEY`. Do not rotate the key casually; re-enter mailbox credentials after a deliberate reset.                                                                                                                                        |
| SMTP authentication fails                      | Verify the mail product, mailbox username and password in Settings. Environment overrides take precedence when configured. Verify SMTP access is allowed by the provider.                                                                                                       |
| SMTP TLS/socket failure                        | Check host, port, certificate trust and outbound TCP connectivity. Use 465 implicit TLS or 587 required STARTTLS. Never set certificate verification to false.                                                                                                                  |
| IMAP test fails while SMTP passes              | Verify IMAP separately, including port 993 TLS and product-specific host. SMTP success does not establish IMAP availability.                                                                                                                                                    |
| Queued sends do not progress                   | Run `npm run jobs` or the combined dev/start command. Inspect Settings heartbeat and the operation error. Check test allowlist, rolling send limits, credentials and Worker synchronization.                                                                                    |
| Outcome Unknown                                | SMTP may have accepted the message. Reconcile Sent using its Message-ID and inspect provider records. Never automatically retry or change state through SQL. A fresh manual outreach after investigation is a separate explicit action.                                         |
| SMTP Accepted, no recipient receipt            | Acceptance is not delivery. Check the controlled recipient inbox/spam folder and synchronized delivery notices. Review SPF, DKIM and DMARC using your provider's domain instructions; the app cannot certify delivery.                                                          |
| Sent copy is missing                           | Discover the special-use Sent folder or set its exact path. Reconcile Sent searches Message-ID before append. A previously interrupted append is not repeated without evidence. Download original MIME through the authenticated message endpoint if manual recovery is needed. |
| Reply does not join a conversation             | Inspect Message-ID/In-Reply-To/References and sender address. Subject alone is intentionally insufficient. Unmatched known-prospect messages appear as separate conversations.                                                                                                  |
| Inbox synchronization stops on a large message | Imports are bounded to 5 MB. Review and move that message to another folder in your mail client, then retry. The checkpoint does not silently advance past the blocked message.                                                                                                 |
| Older replies are missing                      | Initial import covers 30 days. Use Settings → Import older inbox history. Missed messages after a successful checkpoint are fetched on reconnection. Only known prospect addresses are imported.                                                                                |
| Tracking remains zero                          | Confirm per-message toggle, registered public HTTPS Worker, D1 migrations, matching shared key, active runner and remote images. Privacy proxies/caching can hide or produce signals.                                                                                           |
| Public opt-outs cannot synchronize             | Restore the Worker and its exact shared key. Active public links deliberately pause sending even if configuration is removed. Do not clear mappings to bypass suppression.                                                                                                      |
| Worker administrator requests fail             | Check HTTPS origin, shared secret length/value and system clocks. Never reuse nonces; signed requests expire after five minutes.                                                                                                                                                |
| SQLite is locked                               | Keep the database on a local persistent disk, use one host and stop unintended duplicate instances. Bounded retries and WAL are enabled; network-share storage is unsupported.                                                                                                  |
| Windows native package fails                   | Use Node 24 x64 and reinstall locked dependencies. If necessary install official C++ Build Tools/Python. Avoid copying node_modules from Linux.                                                                                                                                 |
| Browser tests lack Chromium                    | Run `npx playwright install chromium`, or set `PLAYWRIGHT_CHROMIUM_EXECUTABLE` to a compatible installed Chromium. Build first.                                                                                                                                                 |

Share only redacted error categories, package/runtime versions and operation identifiers for diagnosis. Never dump `.env`, credentials, full tracking URLs or entire mailbox payloads. See validation.md for the checks actually executed in this environment.

Owner password recovery requires local filesystem access: run `npm run setup -- --reset-owner` interactively. This revokes all sessions and replaces the owner while preserving CRM records. Protect local shell access accordingly.
